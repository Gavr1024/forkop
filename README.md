# Forkop-mod
> Небольшая модификация проекта [Forkop](https://github.com/ushan0v/forkop).
> **Поскольку проект долго не обновляется, появился ряд проблем с поддержкой новой версии Sing-Box 1.14 и пакета rpcd-mod-file, пришлось доработать его в первую очередь для себя, но может кому еще пригодится.**

### Установка

```sh
sh <(wget -O - https://raw.githubusercontent.com/Gavr1024/forkop/main/install.sh)
```

### Что нового в этом форке

- Forkop нормально работает и с новым sing-box 1.14, и со старыми 1.13.

- Можно полностью исключить устройство из прокси.

- Можно исключить устройство только в одной секции.

- Торренты идут напрямую, не через прокси.

- В списке DNS появились OpenDNS, AliDNS и Яндекс.

- Можно выбрать и поставить конкретную версию sing-box, не только последнюю. В списке только те версии, которые реально ставятся на роутер.

- Обновление не занимает лишнее место на флешке: старая копия больше не дублируется. Если обновление сорвётся, старая версия сама не вернётся — нужно поставить заново.

- Списки правил можно сохранить на флэшку и пользоваться ими, если интернет до репозитория пропал. На панели видно, какие списки уже лежат локально, и их можно скачать кнопкой сразу.

- Появились «слоты» конфига: один набор настроек для ситуации «пинг есть», другой — «пинга нет». Роутер сам переключается. Можно указать запасной адрес для проверки; онлайн считается, если отвечает хотя бы один. Настройки переключателя пишутся во все сохранённые слоты сразу. Рядом с адресами видно время ответа. Если роутер включился с «не тем» слотом, пакет пытается выбрать рабочий сам.

- В правилах секции можно ставить галочки сразу на несколько списков правил, а не добавлять по одному.

- Сборка через локальный Image Builder под новые прошивки OpenWrt (apk) больше не ломается на скриптах установки.

- Два ядра сразу. В каждой секции можно выбрать sing-box или Xray. Оба могут работать вместе. Xray ставится и обновляется во вкладке «Компоненты», как sing-box. Ссылки vless / vmess / trojan / ss / socks / hysteria2 собираются в конфиг Xray так же, как раньше в sing-box.

- Информация и диагностика. В системной информации видна версия Xray. В диагностике — проверки Xray и кнопка «показать его конфиг». На информационной панели видно, какие секции идут через какое ядро.

- Трафик самого роутера. В настройках галочка и выбор секции: исходящий трафик роутера (обновления, wget и т.п.) идёт через выбранную секцию. Пинг при этом остаётся прямым.

- Перезапуск интерфейсов. Можно указать, какие сетевые интерфейсы поднять заново после старта Forkop, и через сколько секунд это сделать.
